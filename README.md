# AI_Epigraph

Epigraph, AI 비문 판독 연구

## 제240회 신라사학회 정기발표회

**나말여초 고승비문의 결락자 추론을 위한 디지털역사학적 접근**  
최치원·최언위·김정언 찬 비문을 중심으로

- 임평섭 — 서강대학교 HUSS 포용사회사업단 연구교수
- 김근하 — 국립부경대학교 해양인문학연구소 전임연구원

### 발표자료

**[HTML 발표자료 보기](https://littlekg87.github.io/AI_Epigraph/)**

총 30장. 폰트와 이미지를 포함하는 독립 HTML 파일입니다. `index.html`을 내려받아 오프라인에서도 열 수 있습니다.

- 방향키: 이전·다음 슬라이드
- 우측 상단 페이지 번호 또는 G: 전체 페이지 목록
- F: 전체 화면 / N: 발표자 메모 / P: 인쇄
- 학습 과정, LoRA 적용 위치, 평가 지표와 후보 비교를 화면에서 조작할 수 있습니다.

### 출처

발표자료 안에 논문·데이터·연구 도판의 출처를 표시했습니다. Noto 폰트의 OFL 고지는 HTML에 포함되어 있습니다. 이타카·아이네아스 도판은 Google DeepMind의 공식 연구 소개 자료를 사용했습니다. 외부 자료의 권리는 각 원저작자에게 있습니다.

디자인 참고: [huangqing-zhigongtu](https://github.com/littlekg87/huangqing-zhigongtu).
